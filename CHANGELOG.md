# Changelog

All notable changes are documented in this file.

## 1.0.0

- Add a production CLI with file, stdin, configuration, strict-mode, format,
  statistics, and output-file support.
- Add recursive redaction with key and path rules, depth limits, array support,
  and circular-input handling.
- Add configurable field aliases, numeric levels, nested error causes, and
  deterministic trace/debug sampling.
- Add batch and streaming NDJSON processing with bounded line size and
  structured diagnostics.
- Add npm package manifest generation and SHA-256 verification.
- Add Node.js 20/22 CI, dependency review, automated triage and review,
  maintainer-gated repository maintenance, artifact validation, and releases.

## 0.3.1

- Add basic normalization, redaction, NDJSON diagnostics, and sampling.
